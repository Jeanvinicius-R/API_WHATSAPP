A profissão

        
O que acontece quando você faz login, envia uma mensagem ou compra pela internet?

        
A tela que você vê é só a vitrine. Quem recebe o pedido, confere as regras, guarda os dados e responde é o back-end — o “motor” invisível dos aplicativos. Quem constrói esse motor é a pessoa desenvolvedora back-end.

    Back-end na prática
    
        
    O QUE ACONTECE POR TRÁS DO BOTÃO?
    
        
    Olha só! Você clicou em um botão, mas foi o back-end que recebeu os dados, processou tudo e pediu o envio da mensagem.
    

        
    
          
    
            
    Como funciona
    
            
      
              
    1. O navegador envia uma requisição POST /api/quiz/enviar-resultado.
      2. 
              
    2. A API Express lê o JSON e confere o consentimento.
      3. 
              
    3. A validação checa DDD, celular, limites e anti-duplicidade.
      4. 
              
    4. A integração com o WhatsApp (whatsapp-web.js) recebe o pedido de envio.
      5. 
              
    5. O resultado volta ao navegador com um código HTTP.
      6. 
            
    
            
    Para um envio real, termine o quiz e peça o resultado no seu WhatsApp. Aqui você pode rodar uma simulação do mesmo fluxo, sem número e sem mensagem real.
